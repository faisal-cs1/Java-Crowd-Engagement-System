# Java-Crowd-Engagement-System
🏙️ BD25 City of Culture System
Role-based application developed as part of a university software engineering group project using Java and Java Swing.

Features
Role-based login system for staff, participants and guests
Participant registration and dashboard system
Activity management and viewing functionality
Guest activity browsing and search functionality
CSV-based data storage and retrieval
GDPR terms and conditions workflow
DIG leader and staff management functionality
Media preview support for activities
Responsive GUI interfaces using Java Swing
Technologies Used
Java
Java Swing
Apache Maven
NetBeans GUI Builder
CSV File Persistence
Java Collections Framework
Object-Oriented Programming (OOP)
Java File I/O

Apache NetBeans
